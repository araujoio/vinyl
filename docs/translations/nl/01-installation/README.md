# installatie

Hoe je de repository kloont, afhankelijkheden installeert en Vinyl lokaal uitvoert.

> [!NOTE]
> Docker-ondersteuning is momenteel in ontwikkeling. Volg voorlopig de onderstaande lokale installatie-instructies.

### Vereisten

Zorg ervoor dat het volgende is geïnstalleerd voordat je begint:

- **Node.js** (v20 of hoger)
- **Git**
- **npm** (of je favoriete pakketbeheerder: `pnpm`, `yarn`, `bun`)

---

### 1. Kloon de repository

```bash
git clone https://github.com/araujoio/vinyl.git
cd vinyl
```

### 2. Installeer afhankelijkheden

Voer de volgende opdracht uit in de hoofdmap van het project:

```bash
npm install
```

### 3. Start de ontwikkelserver

```bash
npm run dev
```

Open na het starten [http://localhost:3000](http://localhost:3000) in je browser om Vinyl te bekijken.
