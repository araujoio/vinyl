# snelstartgids

Vinyl is een moderne, open source web-muziekspeler ontworpen om muziek te verspreiden.

Het brengt deze elementen samen in een open en aanpasbaar muziekplatform, dat vertrouwde muziekdiensten combineert met een verzorgde interface en een moderne architectuur.

Gebouwd rond vijf kernprincipes:

- **Open Code:** Een volledig open muziekspeler waarbij elke laag, van interface tot afspeelbediening, kan worden verkend, aangepast en uitgebreid.
- **Real-Time Catalog:** Ontdek live hitlijsten, bekijk complete discografieën, lees synchrone songteksten en bekijk officiële videoclips op aanvraag.
- **Personal Library:** Maak eigen afspeellijsten, bewaar favoriete nummers en albums, beheer je wachtrij en ga verder waar je gebleven was.
- **Beautiful Defaults:** Zorgvuldig ontworpen lichte, donkere en AMOLED-thema's voor een gepolijste ervaring direct uit de doos.
- **Multi-Language Support:** Ondersteuning voor meerdere talen, zodat luisteraars over de hele wereld van de speler kunnen genieten.
