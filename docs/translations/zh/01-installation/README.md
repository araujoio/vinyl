# 安装指南

如何克隆代码仓库、安装依赖并在本地运行 Vinyl。

> [!NOTE]
> Docker 容器化支持正在开发中。目前请按照下方的本地配置步骤进行操作。

### 环境要求

在开始之前，请确保已安装以下工具：

- **Node.js**（推荐 v20 或更高版本）
- **Git**
- **npm**（或您喜欢的包管理器：`pnpm`、`yarn`、`bun`）

---

### 1. 克隆代码仓库

```bash
git clone https://github.com/araujoio/vinyl.git
cd vinyl
```

### 2. 安装依赖项

在项目根目录下运行以下命令：

```bash
npm install
```

### 3. 启动开发服务器

```bash
npm run dev
```

启动后，在浏览器中打开 [http://localhost:3000](http://localhost:3000) 即可查看运行中的 Vinyl。
