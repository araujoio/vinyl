# 快速入门

Vinyl 是一款专为音乐分发打造的现代开源 Web 音乐播放器。

它将熟悉的音乐服务功能与精美界面以及现代化、可扩展的架构融为一体，构建了一个开放且高度可定制的音乐平台。

围绕五大核心原则构建：

- **Open Code:** 完全开放的播放器，从界面到播放控制的每一层均可自由探索、定制与扩展。
- **Real-Time Catalog:** 探索实时榜单、完整艺人作品集、同步滚动歌词以及点播官方音乐视频。
- **Personal Library:** 创建自定义歌单、收藏喜爱的曲目与专辑、管理播放队列，随时随地继续聆听。
- **Beautiful Defaults:** 精心设计的亮色、暗色和 AMOLED 黑色主题，开箱即享精致视觉体验。
- **Multi-Language Support:** 原生多语言支持，让全球各地的乐迷都能无障碍使用。
