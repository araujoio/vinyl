# vinyl

Nowoczesna aplikacja internetowa do odtwarzania ulubionych utworów, odkrywania nowych albumów i tworzenia playlist bezpośrednio w przeglądarce. Lekka, otwartoźródłowa i stworzona do codziennego słuchania muzyki.
