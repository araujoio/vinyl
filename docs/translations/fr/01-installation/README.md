# installation

Comment cloner le dépôt, installer les dépendances et exécuter Vinyl localement.

> [!NOTE]
> La conteneurisation Docker est actuellement en cours de développement. Pour l'instant, suivez les instructions de configuration locale ci-dessous.

### Prérequis

Avant de commencer, assurez-vous d'avoir installé :

- **Node.js** (v20 ou supérieur)
- **Git**
- **npm** (ou votre gestionnaire préféré : `pnpm`, `yarn`, `bun`)

---

### 1. Cloner le dépôt

```bash
git clone https://github.com/araujoio/vinyl.git
cd vinyl
```

### 2. Installer les dépendances

Exécutez la commande suivante à la racine du projet :

```bash
npm install
```

### 3. Lancer le serveur de développement

```bash
npm run dev
```

Une fois lancé, ouvrez [http://localhost:3000](http://localhost:3000) dans votre navigateur pour voir Vinyl fonctionner.
