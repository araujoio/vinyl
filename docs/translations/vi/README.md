# vinyl

Một ứng dụng web âm nhạc hiện đại để phát các bản nhạc yêu thích, khám phá album mới và tạo danh sách phát trực tiếp trên trình duyệt của bạn. Nhẹ, mã nguồn mở và được xây dựng cho việc nghe nhạc hàng ngày.
