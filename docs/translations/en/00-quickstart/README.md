# quick start

Vinyl is a modern web music player, open source and designed to distribute songs.

It brings these elements together in one open and customizable music platform, combining familiar music services with a carefully crafted interface and a modern, extensible architecture.

Built around five core principles:

- **Open Code:** A fully open music player where every layer, from the interface to the playback controls, can be explored, customized, and extended.
- **Real-Time Catalog:** Discover live charts, explore complete artist discographies, read time-synced lyrics, and watch official music videos on demand.
- **Personal Library:** Build custom playlists, save favorite tracks and albums, manage your playback queue, and pick up right where you left off.
- **Beautiful Defaults:** Carefully designed Light, Dark, and AMOLED themes, delivering a polished experience right out of the box.
- **Multi-Language Support:** Native localization across multiple languages, making the player accessible to listeners worldwide.
