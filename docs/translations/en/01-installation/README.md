# installation

How to clone the repository, install dependencies, and run Vinyl locally.

> [!NOTE]
> Docker containerization is currently under development. For now, please follow the local setup instructions below.

### Prerequisites

Before getting started, make sure you have the following installed:

- **Node.js** (v20 or later)
- **Git**
- **npm** (or your preferred package manager: `pnpm`, `yarn`, `bun`)

---

### 1. Clone the repository

```bash
git clone https://github.com/araujoio/vinyl.git
cd vinyl
```

### 2. Install dependencies

Run the following command from the project root:

```bash
npm install
```

### 3. Run the development server

```bash
npm run dev
```

Once started, open [http://localhost:3000](http://localhost:3000) in your browser to see Vinyl running.
