# クイックスタート

Vinyl は、音楽を届けるために設計されたオープンソースのモダンな音楽ウェブプレーヤーです。

おなじみの音楽機能、洗練されたインターフェース、拡張性に優れた最新アーキテクチャを1つのオープンなプラットフォームに統合しています。

5つの基本理念に基づいて構築されています：

- **Open Code:** UIから再生エンジンに至るまで、すべてのレイヤーを探索、カスタマイズ、拡張できる完全にオープンな設計。
- **Real-Time Catalog:** リアルタイムのチャート、アーティストの全ディスコグラフィ、同期歌詞、公式ミュージックビデオのオンデマンド再生に対応。
- **Personal Library:** カスタムプレイリストの作成、お気に入りの楽曲やアルバムの保存、再生キューの管理に対応し、いつでも続きから楽しめます。
- **Beautiful Defaults:** 日常のリスニングに最適化された、美しいライト、ダーク、AMOLEDテーマを標準搭載。
- **Multi-Language Support:** 複数言語のネイティブ多言語対応により、世界中のリスナーが快適に利用可能。
