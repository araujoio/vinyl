# التثبيت

كيفية استنساخ المستودع وتثبيت الحزم وتشغيل Vinyl محلياً.

> [!NOTE]
> الدعم عبر حاويات Docker قيد التطوير حالياً. يُرجى اتباع خطوات التثبيت المحلي الموضحة أدناه.

### المتطلبات الأساسية

قبل البدء، تأكد من تثبيت الأدوات التالية على جهازك:

- **Node.js** (الإصدار 20 أو أحدث)
- **Git**
- **npm** (أو مدير الحزم المفضل لديك: `pnpm` أو `yarn` أو `bun`)

---

### 1. استنساخ المستودع

```bash
git clone https://github.com/araujoio/vinyl.git
cd vinyl
```

### 2. تثبيت الحزم البرمجية

نفّذ الأمر التالي في المجلد الرئيسي للمشروع:

```bash
npm install
```

### 3. تشغيل خادم التطوير

```bash
npm run dev
```

بعد التشغيل، افتح الرابط [http://localhost:3000](http://localhost:3000) في المتصفح لرؤية Vinyl يعمل.
