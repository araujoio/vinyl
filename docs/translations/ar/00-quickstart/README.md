# البداية السريعة

Vinyl هو مشغل موسيقى ويب حديث ومفتوح المصدر مصمم لتوزيع الموسيقى والاستماع إليها بسلاسة.

يجمع هذا المشروع بين واجهة مستخدم متقنة وخدمات موسيقية مألوفة ضمن بنية برمجية حديثة وقابلة للتوسيع.

مبني على خمسة مبادئ أساسية:

- **Open Code:** مشغل موسيقى مفتوح بالكامل حيث يمكن فحص وتخصيص وتوسيع كل طبقة، من الواجهة إلى محرك التشغيل.
- **Real-Time Catalog:** استكشف القوائم الأكثر استماعاً، وتصفح ديسكوغرافيا الفنانين الكاملة، واستمتع بكلمات الأغاني المتزامنة والفيديوهات الموسيقية الرسمية.
- **Personal Library:** أنشئ قوائم تشغيل مخصصة، واحفظ الأغاني والألبومات المفضلة، وتحكم في قائمة الانتظار للمتابعة من حيث توقفت.
- **Beautiful Defaults:** ثيمات الفاتح والداكن و AMOLED مصممة بعناية لتقديم تجربة استماع متميزة بمجرد التثبيت.
- **Multi-Language Support:** دعم مدمج للغات متعددة لتوفير تجربة مريحة للمستمعين حول العالم.
