# vinyl

เว็บแอปพลิเคชันเพลงที่ทันสมัยสำหรับฟังเพลงโปรด สำรวจอัลบั้มใหม่ และสร้างเพลย์ลิสต์ได้โดยตรงในเบราว์เซอร์ของคุณ น้ำหนักเบา โอเพ่นซอร์ส และสร้างขึ้นสำหรับการฟังเพลงในชีวิตประจำวัน
