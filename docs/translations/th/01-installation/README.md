# การติดตั้ง

วิธีโคลนที่เก็บข้อมูล ติดตั้งแพ็กเกจ และรัน Vinyl บนเครื่องของคุณ

> [!NOTE]
> การรองรับ Docker อยู่ระหว่างการพัฒนา ในขณะนี้โปรดทำตามขั้นตอนการติดตั้งภายในเครื่องด้านล่างนี้

### สิ่งที่ต้องเตรียมพร้อม

ก่อนเริ่มต้น ตรวจสอบให้แน่ใจว่าคุณได้ติดตั้งสิ่งต่อไปนี้แล้ว:

- **Node.js** (เวอร์ชัน 20 ขึ้นไป)
- **Git**
- **npm** (หรือแพ็กเกจที่คุณต้องการ: `pnpm`, `yarn`, `bun`)

---

### 1. โคลนที่เก็บข้อมูล (Repository)

```bash
git clone https://github.com/araujoio/vinyl.git
cd vinyl
```

### 2. ติดตั้งแพ็กเกจและส่วนประกอบ

รันคำสั่งต่อไปนี้ในไดเรกทอรีรากของโปรเจกต์:

```bash
npm install
```

### 3. เริ่มต้นเซิร์ฟเวอร์สำหรับการพัฒนา

```bash
npm run dev
```

เมื่อเริ่มต้นแล้ว ให้เปิด [http://localhost:3000](http://localhost:3000) ในเบราว์เซอร์เพื่อดู Vinyl กำลังทำงาน
