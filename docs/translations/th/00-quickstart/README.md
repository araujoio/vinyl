# เริ่มต้นใช้งานด่วน

Vinyl เป็นเว็บเครื่องเล่นเพลงที่ทันสมัย เป็นโอเพ่นซอร์ส และออกแบบมาสำหรับการสตรีมเพลง

รวบรวมฟังก์ชันเพลงยอดนิยมเข้ากับอินเทอร์เฟซที่สร้างขึ้นอย่างประณีตและสถาปัตยกรรมที่ยืดหยุ่นขยายได้

สร้างขึ้นจากหลักการสำคัญ 5 ประการ:

- **Open Code:** เครื่องเล่นเพลงที่เปิดเผยโค้ดทั้งหมด ตั้งแต่อินเทอร์เฟซจนถึงการควบคุมการเล่นเพลง สามารถสำรวจ ปรับแต่ง และพัฒนาต่อยอดได้
- **Real-Time Catalog:** ค้นพบชาร์ตเพลงแบบเรียลไทม์ สำรวจผลงานเพลงทั้งหมดของศิลปิน อ่านเนื้อเพลงที่ซิงค์ตามเวลา และดูมิวสิควิดีโออย่างเป็นทางการ
- **Personal Library:** สร้างเพลย์ลิสต์ส่วนตัว บันทึกแทร็กและอัลบั้มโปรด จัดการคิวเพลง และฟังต่อจากจุดที่คุณค้างไว้ได้อย่างราบรื่น
- **Beautiful Defaults:** ธีมสว่าง, มืด และ AMOLED ที่ออกแบบมาอย่างสวยงามพร้อมให้ประสบการณ์ที่สมบูรณ์แบบทันที
- **Multi-Language Support:** รองรับหลายภาษาในตัว เพื่อให้ผู้ฟังทั่วโลกใช้งานได้อย่างสะดวกสบาย
