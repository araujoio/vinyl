# installazione

Come clonare il repository, installare le dipendenze ed eseguire Vinyl localmente.

> [!NOTE]
> La containerizzazione con Docker è attualmente in fase di sviluppo. Per ora, segui le istruzioni di configurazione locale qui sotto.

### Prerequisiti

Prima di iniziare, assicurati di avere installato:

- **Node.js** (v20 o successivo)
- **Git**
- **npm** (o il tuo gestore preferito: `pnpm`, `yarn`, `bun`)

---

### 1. Clonare il repository

```bash
git clone https://github.com/araujoio/vinyl.git
cd vinyl
```

### 2. Installare le dipendenze

Esegui il seguente comando nella radice del progetto:

```bash
npm install
```

### 3. Avviare il server di sviluppo

```bash
npm run dev
```

Una volta avviato, apri [http://localhost:3000](http://localhost:3000) nel tuo browser per vedere Vinyl in esecuzione.
