# швидкий старт

Vinyl — це сучасний веб-плеєр із відкритим кодом, створений для прослуховування та поширення музики.

Він поєднує ці елементи у відкритій платформі, що поєднує знайомі музичні сервіси з продуманим інтерфейсом та сучасною архітектурою.

Побудований на п'яти ключових принципах:

- **Open Code:** Повністю відкритий плеєр, де кожен шар — від інтерфейсу до керування відтворенням — можна досліджувати, налаштовувати та розширювати.
- **Real-Time Catalog:** Відкривайте чарти в реальному часі, повні дискографії виконавців, синхронізовані тексти пісень та офіційні кліпи на вимогу.
- **Personal Library:** Створюйте власні списки відтворення, зберігайте улюблені треки й альбоми, керуйте чергою та продовжуйте слухати з того місця, де зупинилися.
- **Beautiful Defaults:** Світла, темна та AMOLED теми, ретельно розроблені для бездоганного прослуховування.
- **Multi-Language Support:** Вбудована підтримка багатьох мов для слухачів з усього світу.
