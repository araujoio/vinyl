# встановлення

Як клонувати репозиторій, встановити залежності та запустити Vinyl локально.

> [!NOTE]
> Підтримка Docker наразі знаходиться в розробці. Поки що дотримуйтесь інструкцій із локального налаштування нижче.

### Вимоги

Перед початком переконайтеся, що у вас встановлено:

- **Node.js** (версія 20 або новіша)
- **Git**
- **npm** (або ваш менеджер пакетів: `pnpm`, `yarn`, `bun`)

---

### 1. Клонувати репозиторій

```bash
git clone https://github.com/araujoio/vinyl.git
cd vinyl
```

### 2. Встановити залежності

Виконайте таку команду в кореневому каталозі проєкту:

```bash
npm install
```

### 3. Запустити сервер розробки

```bash
npm run dev
```

Після запуску відкрийте [http://localhost:3000](http://localhost:3000) у веб-переглядачі, щоб побачити Vinyl.
