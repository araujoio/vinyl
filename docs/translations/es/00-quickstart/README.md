# inicio rápido

Vinyl es un reproductor de música web moderno, de código abierto y diseñado para distribuir canciones.

Reúne estos elementos en una plataforma musical abierta y personalizable, combinando servicios conocidos con una interfaz cuidada y una arquitectura moderna y extensible.

Construido en torno a cinco principios fundamentales:

- **Open Code:** Un reproductor totalmente abierto donde cada capa, desde la interfaz hasta los controles de reproducción, se puede explorar, personalizar y extender.
- **Real-Time Catalog:** Descubre listas de éxitos en tiempo real, explora discografías completas, lee letras sincronizadas y mira vídeos musicales oficiales bajo demanda.
- **Personal Library:** Crea listas de reproducción personalizadas, guarda pistas y álbumes favoritos, administra tu cola de reproducción y continúa donde lo dejaste.
- **Beautiful Defaults:** Temas Claro, Oscuro y AMOLED cuidadosamente diseñados, ofreciendo una experiencia impecable lista para usar.
- **Multi-Language Support:** Localización nativa en múltiples idiomas, haciendo que el reproductor sea accesible para oyentes de todo el mundo.
