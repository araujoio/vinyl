# instalación

Cómo clonar el repositorio, instalar dependencias y ejecutar Vinyl localmente.

> [!NOTE]
> La contenedorización con Docker está actualmente en desarrollo. Por ahora, sigue las instrucciones de configuración local a continuación.

### Requisitos previos

Antes de comenzar, asegúrate de tener instalado:

- **Node.js** (v20 o superior)
- **Git**
- **npm** (o tu gestor preferido: `pnpm`, `yarn`, `bun`)

---

### 1. Clonar el repositorio

```bash
git clone https://github.com/araujoio/vinyl.git
cd vinyl
```

### 2. Instalar dependencias

Ejecuta el siguiente comando en la raíz del proyecto:

```bash
npm install
```

### 3. Iniciar el servidor de desarrollo

```bash
npm run dev
```

Una vez iniciado, abre [http://localhost:3000](http://localhost:3000) en tu navegador para ver Vinyl en funcionamiento.
