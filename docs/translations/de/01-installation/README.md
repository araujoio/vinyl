# installation

So klonen Sie das Repository, installieren Abhängigkeiten und führen Vinyl lokal aus.

> [!NOTE]
> Die Docker-Containerisierung befindet sich derzeit in Entwicklung. Bitte nutzen Sie vorerst die folgende lokale Einrichtung.

### Voraussetzungen

Stellen Sie vor dem Start sicher, dass Folgendes installiert ist:

- **Node.js** (v20 oder höher)
- **Git**
- **npm** (oder Ihr bevorzugter Paketmanager: `pnpm`, `yarn`, `bun`)

---

### 1. Repository klonen

```bash
git clone https://github.com/araujoio/vinyl.git
cd vinyl
```

### 2. Abhängigkeiten installieren

Führen Sie den folgenden Befehl im Projektstammverzeichnis aus:

```bash
npm install
```

### 3. Entwicklungsserver starten

```bash
npm run dev
```

Öffnen Sie nach dem Start [http://localhost:3000](http://localhost:3000) im Browser, um Vinyl zu sehen.
