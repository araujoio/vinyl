# vinyl

Eine moderne Musik-Web-App, mit der Sie Ihre Lieblingstitel abspielen, neue Alben entdecken und Playlists direkt im Browser erstellen können. Leichtgewichtig, Open Source und für das tägliche Musikhören entwickelt.
