# schnellstart

Vinyl ist ein moderner Web-Musikplayer, quelloffen und darauf ausgelegt, Musik bereitzustellen.

Er vereint diese Elemente in einer offenen und anpassbaren Musikplattform, die vertraute Musikdienste mit einer sorgfältig gestalteten Benutzeroberfläche und einer modernen Architektur kombiniert.

Aufgebaut auf fünf Grundprinzipien:

- **Open Code:** Ein vollständig offener Player, bei dem jede Ebene – von der Oberfläche bis zur Wiedergabesteuerung – erkundet, angepasst und erweitert werden kann.
- **Real-Time Catalog:** Entdecken Sie Live-Charts, stöbern Sie in kompletten Diskografien, lesen Sie zeitsynchronisierte Songtexte und sehen Sie offizielle Musikvideos auf Abruf.
- **Personal Library:** Erstellen Sie eigene Playlists, speichern Sie Lieblingstracks und -alben, verwalten Sie die Warteschlange und hören Sie genau dort weiter, wo Sie aufgehört haben.
- **Beautiful Defaults:** Sorgfältig gestaltete Themes in Hell, Dunkel und AMOLED für ein sofortiges, erstklassiges Hörerlebnis.
- **Multi-Language Support:** Native Lokalisierung in mehreren Sprachen, damit Hörer weltweit den Player in ihrer Sprache nutzen können.
