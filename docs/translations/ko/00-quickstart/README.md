# 빠른 시작

Vinyl은 음악 배포를 위해 설계된 최신의 오픈 소스 웹 음악 플레이어입니다.

친숙한 음악 서비스 기능과 정교하게 디자인된 인터페이스, 현대적이고 확장 가능한 아키텍처를 하나의 오픈 플랫폼으로 결합했습니다.

5가지 핵심 원칙을 바탕으로 구축되었습니다:

- **Open Code:** 인터페이스부터 재생 컨트롤에 이르기까지 모든 계층을 탐색, 수정 및 확장할 수 있는 완전한 오픈 플레이어.
- **Real-Time Catalog:** 실시간 차트, 아티스트의 전체 디스코그래피 탐색, 실시간 동기화 가사 및 공식 뮤직비디오 스트리밍 지원.
- **Personal Library:** 맞춤 재생목록 생성, 즐겨찾는 트랙 및 앨범 저장, 재생 대기열 관리 및 이어서 듣기 기능.
- **Beautiful Defaults:** 라이트, 다크, AMOLED 테마를 기본 제공하여 바로 사용할 수 있는 정교한 사용자 경험.
- **Multi-Language Support:** 다국어 기본 지원을 통해 전 세계 사용자가 편리하게 이용 가능.
