# instalação

Como clonar o repositório, instalar dependências e rodar o Vinyl localmente.

> [!NOTE]
> A conteinerização com Docker está atualmente em desenvolvimento. Por enquanto, siga as instruções de configuração local abaixo.

### Pré-requisitos

Antes de começar, certifique-se de ter instalado em sua máquina:

- **Node.js** (v20 ou superior)
- **Git**
- **npm** (ou seu gerenciador preferido: `pnpm`, `yarn`, `bun`)

---

### 1. Clonar o repositório

```bash
git clone https://github.com/araujoio/vinyl.git
cd vinyl
```

### 2. Instalar as dependências

Execute o comando a seguir na raiz do projeto:

```bash
npm install
```

### 3. Iniciar o servidor de desenvolvimento

```bash
npm run dev
```

Após iniciar, abra [http://localhost:3000](http://localhost:3000) no seu navegador para ver o Vinyl rodando.
