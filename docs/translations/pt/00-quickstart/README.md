# início rápido

O Vinyl é um player de música web moderno, open source e projetado para distribuir músicas.

Ele reúne esses elementos em uma plataforma de música aberta e customizável, combinando serviços conhecidos com uma interface cuidadosamente projetada e uma arquitetura moderna e extensível.

Construído em torno de cinco princípios fundamentais:

- **Open Code:** Um player de música totalmente aberto onde cada camada, desde a interface até os controles de reprodução, pode ser explorada, customizada e estendida.
- **Real-Time Catalog:** Descubra paradas em tempo real, explore discografias completas de artistas, leia letras sincronizadas e assista a clipes oficiais sob demanda.
- **Personal Library:** Crie playlists personalizadas, salve faixas e álbuns favoritos, gerencie sua fila de reprodução e continue exatamente de onde parou.
- **Beautiful Defaults:** Temas Claro, Escuro e AMOLED cuidadosamente projetados, entregando uma experiência refinada pronta para o uso.
- **Multi-Language Support:** Localização nativa em múltiplos idiomas, tornando o player acessível para ouvintes do mundo inteiro.
