# установка

Как клонировать репозиторий, установить зависимости и запустить Vinyl локально.

> [!NOTE]
> Поддержка Docker находится в разработке. Пока следуйте инструкциям по локальной настройке ниже.

### Требования

Перед началом убедитесь, что у вас установлены:

- **Node.js** (версия 20 или новее)
- **Git**
- **npm** (или ваш менеджер пакетов: `pnpm`, `yarn`, `bun`)

---

### 1. Клонирование репозитория

```bash
git clone https://github.com/araujoio/vinyl.git
cd vinyl
```

### 2. Установка зависимостей

Выполните следующую команду в корневой папке проекта:

```bash
npm install
```

### 3. Запуск сервера разработки

```bash
npm run dev
```

После запуска откройте [http://localhost:3000](http://localhost:3000) в браузере, чтобы увидеть Vinyl в работе.
