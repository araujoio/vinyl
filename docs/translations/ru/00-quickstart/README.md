# быстрый старт

Vinyl — это современный веб-плеер с открытым исходным кодом, созданный для распространения музыки.

Он объединяет эти элементы на открытой и настраиваемой платформе, сочетая привычные музыкальные функции с продуманным интерфейсом и современной архитектурой.

Построен на пяти ключевых принципах:

- **Open Code:** Полностью открытый плеер, где каждый уровень — от интерфейса до управления воспроизведением — можно исследовать, настраивать и расширять.
- **Real-Time Catalog:** Открывайте чарты в реальном времени, изучайте полные дискографии, читайте синхронизированные тексты песен и смотрите официальные клипы.
- **Personal Library:** Создавайте плейлисты, сохраняйте любимые треки и альбомы, управляйте очередью и продолжайте прослушивание с того места, где остановились.
- **Beautiful Defaults:** Тщательно проработанные светлая, тёмная и AMOLED-темы, готовые к повседневному использованию.
- **Multi-Language Support:** Встроенная поддержка множества языков для слушателей по всему миру.
