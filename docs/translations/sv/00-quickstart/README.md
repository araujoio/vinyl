# snabbstart

Vinyl är en modern webbmusikspelare med öppen källkod, skapad för att sprida musik.

Den förenar dessa delar i en öppen och anpassningsbar musikplattform som kombinerar välkända funktioner med ett omsorgsfullt gränssnitt och en modern arkitektur.

Byggd kring fem grundläggande principer:

- **Open Code:** En helt öppen spelare där varje lager, från gränssnitt till uppspelningskontroller, kan utforskas, anpassas och utökas.
- **Real-Time Catalog:** Upptäck topplistor i realtid, utforska kompletta diskografier, läs synkroniserade låttexter och se officiella musikvideor on-demand.
- **Personal Library:** Skapa spellistor, spara favoritlåtar och album, hantera uppspelningskön och fortsätt lyssna där du slutade.
- **Beautiful Defaults:** Noggrant designade ljusa, mörka och AMOLED-teman för en polerad upplevelse direkt.
- **Multi-Language Support:** Inbyggt stöd för flera språk som gör spelaren tillgänglig för lyssnare världen över.
