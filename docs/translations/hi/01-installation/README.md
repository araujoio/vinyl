# संस्थापना (installation)

रिपॉजिटरी को क्लोन करने, निर्भरताएं इंस्टॉल करने और Vinyl को स्थानीय रूप से चलाने का तरीका।

> [!NOTE]
> Docker कंटेनरीकरण वर्तमान में विकास के अधीन है। कृपया अभी के लिए नीचे दिए गए स्थानीय सेटअप निर्देशों का पालन करें।

### आवश्यक शर्तें

शुरू करने से पहले, सुनिश्चित करें कि आपके पास निम्नलिखित इंस्टॉल हैं:

- **Node.js** (v20 या उच्चतर)
- **Git**
- **npm** (या आपका पसंदीदा पैकेज मैनेजर: `pnpm`, `yarn`, `bun`)

---

### 1. रिपॉजिटरी क्लोन करें

```bash
git clone https://github.com/araujoio/vinyl.git
cd vinyl
```

### 2. निर्भरताएं इंस्टॉल करें

प्रोजेक्ट के मुख्य फ़ोल्डर में निम्न कमांड चलाएँ:

```bash
npm install
```

### 3. डेवलपमेंट सर्वर शुरू करें

```bash
npm run dev
```

शुरू होने के बाद, Vinyl को देखने के लिए अपने ब्राउज़र में [http://localhost:3000](http://localhost:3000) खोलें।
