# त्वरित शुरुआत (quickstart)

Vinyl एक आधुनिक, ओपन-सोर्स वेब म्यूजिक प्लेयर है जो संगीत को आसानी से स्ट्रीम करने के लिए बनाया गया है।

यह एक खुले और कस्टमाइज़ करने योग्य प्लेटफ़ॉर्म में लोकप्रिय संगीत सेवाओं, आकर्षक इंटरफ़ेस और आधुनिक आर्किटेक्चर को एक साथ लाता है।

पांच मुख्य सिद्धांतों पर आधारित:

- **Open Code:** पूरी तरह से ओपन प्लेयर जहां इंटरफ़ेस से लेकर प्लेबैक कंट्रोल तक हर परत को देखा, बदला और विस्तारित किया जा सकता है।
- **Real-Time Catalog:** रीयल-टाइम चार्ट खोजें, कलाकारों की पूरी डिस्कोग्राफी देखें, सिंक किए गए बोल पढ़ें और मांग पर आधिकारिक वीडियो देखें।
- **Personal Library:** अपनी प्लेलिस्ट बनाएं, पसंदीदा गाने और एल्बम सहेजें, प्लेबैक कतार प्रबंधित करें और वहीं से शुरू करें जहां आपने छोड़ा था।
- **Beautiful Defaults:** लाइट, डार्क और AMOLED थीम, जो सीधे उपयोग के लिए एक परिष्कृत अनुभव प्रदान करती हैं।
- **Multi-Language Support:** कई भाषाओं का स्थानीय समर्थन, जिससे दुनिया भर के संगीत प्रेमी आसानी से इसका आनंद ले सकते हैं।
